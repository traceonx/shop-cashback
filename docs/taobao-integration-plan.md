# 淘宝联盟接入准备

核对日期：2026-10-17。当前阶段为官方文档调研与实现方案；未注册淘宝插件，未验证实际应用权限。

## 接口与权限

| 能力 | 官方接口 | 用途与限制 |
| --- | --- | --- |
| 转链 | [taobao.tbk.dg.general.link.convert](https://developer.alibaba.com/docs/api.htm?apiId=65409) | 推广者路线。adzone_id 为 PID 第三段。链接、淘口令转链有邀约权限限制；主站选品场景还涉及 relation_id 与场景参数，不能统一写死。 |
| 物料 | [taobao.tbk.dg.material.optional.upgrade](https://developer.alibaba.com/docs/api.htm?apiId=64759) | 查询商品和推广物料。用于补充信息，不能把关键词搜索首条结果直接当作输入商品。 |
| 订单 | [taobao.tbk.order.details.get](https://developer.alibaba.com/docs/api.htm?apiId=43328) | 推广订单，非个人购物订单；分页需回传 position_index。 |
| 售后 | [taobao.tbk.order.refund.get](https://developer.alibaba.com/docs/api.htm?apiId=65180) | 后续单独对接退款同步。 |
| 用户标识 | [taobao.tbk.uvid.encrypt](https://developer.alibaba.com/docs/api.htm?apiId=68029) | 用户归属候选方案，实施前核对应用能力及绑定流程。 |

“不需要授权”是接口不要求用户 session，不代表所有应用自动具有调用权限。先按自用推广者接口准备；如实际应用为服务商，则改用对应 sc 接口并实现用户授权、令牌加密与刷新。不能把两个路线的参数混用。

## 后台配置设计

渠道配置新增淘宝联盟卡片，继续使用分组详情弹窗。基础字段：AppKey、AppSecret、完整 PID、推广位 adzoneId。PID 保存时解析并校验其第三段与推广位一致；场景、渠道关系等字段按实际获批能力展示。不能填写京东 siteId 或用本地用户编号代替淘宝平台分配的身份标识。

连接检测分别显示转链、物料、订单的结果；一个接口成功不能代表全部已开通。密钥加密保存，详情只允许超管查看，审计中不记录凭证。

## 本项目需要改造的地方

1. 新建 apps/server/src/platforms/taobao/，独立实现 TOP 签名、HTTPS 请求、错误与响应解析；验证完成后再加入 registry.ts。沿用公共配置存储和审计，不复制京东实现。
2. types.ts 的 queryOrders 增加可选不透明分页游标；order-sync.ts 将返回游标与本页数据一起提交。当前只有 page 和 hasMore，不足以覆盖淘宝位点分页。新窗口必须清空旧位点，任务重启从持久化位点恢复。
3. 把公共时间查询模式改为具名语义，由插件映射。淘宝更新时间为 query_type=4，不能直接沿用当前京东的数值 3。
4. 订单区分收货与结算：淘宝 11/12/13/14/3 分别代表未付、已付、关闭、确认收货、结算成功。内部状态与结算资格应分开，不能确认收货即发钱。历史范围及单次查询窗口需在实现前核对官方限制，不直接照搬京东 90 天。
5. 归属采用平台账号范围内的标识映射。special_id 是会员运营标识，relation_id 是渠道关系；不把一个渠道下所有订单归给同一用户。external_id、UVID 等透传与回传能力需用实际订单验证，缺证据时保持未归属。
6. 商品输入支持需要相应权限的链接及口令。平台识别契约需允许结构化输入，不能强制所有输入为 HTTPS URL。不从浏览器 Cookie 获取登录态。
7. 金额逐字段核对单位，以整数分计算；保留原始响应、商品图片和长订单号。用户要求付款列展示计佣金额，适配时必须明确对应口径，不能把淘宝其他金额字段无条件套入。
8. 预览同时展示商品、优惠、预计返现及查询失败原因。未获取到数据时不使用演示价格，不把联盟佣金直接等同用户返现金额。

## 实施与验收顺序

- 确认应用属于推广者还是服务商，并核查三类接口权限；准备 AppKey、AppSecret 与 PID，在后台输入，不写入代码。
- 完成插件请求层和配置卡片，以一条真实商品链接验证转链及价格优惠；再验证淘口令入口。
- 实现分页位点及按更新时间补偿，以已知推广订单核对状态、金额、图片及订单号。
- 验证至少两个不同用户的归属隔离；没有验证前不自动发放返现。
- 回归京东同步、重复订单幂等、失败恢复、秘密脱敏及后台超管权限。开发阶段不构建或更新 Docker 镜像。

待确认：当前淘宝应用类型、已获批接口/场景、返利用户绑定方式、真实订单字段和退款规则。商品详情升级版（apiId=64757）链接已找到，但正文抓取超时，尚未完成逐字段核对。
