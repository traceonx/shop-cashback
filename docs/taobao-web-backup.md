# 淘宝联盟网页登录备用通道

## 登录

1. 在「联盟配置 → 淘宝联盟」保存默认推广位 PID。
2. 点击「登录淘宝联盟」。不需要登录码、配对码、回调地址或单独安装助手。
3. 在官方登录页面选择二维码，用手机淘宝扫码并确认。请确认账号与默认 PID 对应。
4. 登录成功后，系统自动验证订单查询并保存会话。后台显示「登录有效」后，选择「主通道不可用时自动备用」或「手动切换到网页通道」，保存配置。

电脑端会打开独立 Chrome 浏览器（没有 Chrome 时尝试 Edge）。Docker 中在后台弹窗显示官方登录画面，可点击切换二维码、刷新二维码。登录窗口十分钟后关闭；关闭弹窗也会取消本次登录。后台可直接重新打开登录。

Docker 镜像内置 Chromium 和中文字体。升级时需要重新构建或拉取新版镜像。独立浏览器目录在 `DATA_DIR/taobao-web-browser`，默认挂载目录 `/app/data`；会话使用现有 `CONFIG_ENCRYPTION_KEY` 加密保存在数据库中。请一并保留数据卷和密钥。

本机开发需安装 Chrome 或 Edge。可选环境变量 `TAOBAO_BROWSER_EXECUTABLE` 指定浏览器可执行文件，`TAOBAO_BROWSER_CHANNEL` 指定 Chrome / Edge 通道。不要指向日常浏览器的用户目录。

## 失效提醒

在「渠道配置 → 企业微信」填写一个管理员 UserID。检测到明确的登录失效时，网页备用请求暂停，并向该管理员提醒一次；失败最多重试三次，重启保留通知状态。重新登录成功后，下次失效可以再次提醒。网络错误、限流和人工验证分别显示，不误报登录过期。

「后台访问地址」用于提醒中的重新登录入口。管理员应能访问该地址；无需在淘宝开放平台配置 OAuth 回调。

新登录验证失败时保留原会话。网页登录和原 AppKey 接口使用不同凭证。旧 OAuth 登录入口、回调与 SC 订单查询已移除；旧 `official-sc` 配置按官方推广者处理，可在后台重新选择主订单数据源。

## 查询范围与限制

- 转链沿用当前用户实际分配的 PID，不重新分配推广位。
- 网页转链接口提供价格、优惠券、佣金率；`promotionPrice` 的券前/券后口径尚未核实，金额不重复减券，也不推算未经确认的返现金额。实际返利以订单为准。
- 网页订单逐日回溯，默认最近 90 天，从最近一天开始。与官方数据按订单及子订单唯一键合并；缺失字段不覆盖已有有效值。
- 所有网页请求共享每分钟上限，包括登录验证、健康检查、转链与订单分页。
- 网站返回验证码或人工验证时，需要在官方页面完成。电脑端可操作浏览器窗口；Docker 的登录画面目前支持点击，复杂拖动验证需要在具备桌面的部署环境中处理。
- 网页内部接口可能变化。单元测试使用模拟响应；上线后需由管理员扫码，确认真实转链和订单查询可用，不能把模拟测试视为真实授权成功。
